# House style

This project follows a shared house style for wording and punctuation. It flags promotional claims, because quality asserted without evidence tells the reader nothing, and vague filler, because it delays the fact the sentence is there to state. It also flags the em dash, because the house typography uses a spaced en dash as in Swedish and British usage. The checks run through [Vale](https://vale.sh) with the [house-style](https://github.com/rubenluthman/house-style) package, and each rule's message states its reason.
